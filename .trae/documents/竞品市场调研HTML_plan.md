# 竞品市场调研报告（类 PPT · HTML）实施计划

## 一、仓库调研结论

### 1.1 需求基线（来自 SRS V4.0）
- **项目**：校园二手交易平台 Multi-Agent 系统 —— 1 个协调管理 Agent ＋ 8 个专家 Agent，核心研究点为"冲突检测 · 三级决策 · 安全一票否决"。
- **四大业务痛点（报告必须呼应）**：P-1 信息不对称、P-2 信任缺失、P-3 议价低效、P-4 纠纷处理难。
- **技术差异化关键词**：LangGraph 1.x 编排、黑板 SSOT、FIPA ACL 消息、纳什参考价议价、加权投票＋全局效用函数、DeepSeek V4 + RuleLLM 双通道兜底。
- **八类冲突场景 C1–C8、15 项功能需求、九类角色**可作为差异化论证素材。

### 1.3 行业调研事实（2025–2026 公开资料，报告内统一标注"公开资料整理/研究测算"）
- 2025 年中国二手电商交易规模约 **8500 亿元**，同比 **+31.77%**；闲鱼 MAU 超 2 亿、年交易约 24.7 亿单；转转注册用户超 4 亿、MAU 约 5000 万、2025 营收破 200 亿元；爱回收（万物新生）为 3C 回收头部。
- 校园：**92.3%** 大学生参与过二手交易、年均 7.2 次；校园潜在市场规模 **超 200 亿元**；匹配成功率仅 **38.7%**、欺诈投诉率 **21.5%**；另一样本（N=1500）显示 **83.6%** 曾遇交易欺诈、**57.3%** 担忧商品质量；高频痛点为隐私泄露、口头约定违约、货不对板、无担保、面交成本高。
- 前沿趋势：Anthropic「Project Deal」让 Claude 自主完成 186 笔二手交易（强模型收益多 70%）；WAIC 2026 智能体成为主角；学术界出现 Supervisor＋专家 Agent＋自动议价的多智能体电商框架（EzyBuyy 等）——与本项目架构同构，佐证"Agentic Commerce"风口。

## 四、视觉与技术方案（world-class 标准）

### 4.1 视觉论点（visual thesis）
"在深空数据驾驶舱中，观看一个多智能体经济体自主运转"——冷静、精密、可信的咨询报告质感，叠加前沿实验系统的生命力。

### 4.2 设计系统
- **色彩**：沿用项目 Token——底 `#060b16/#0a1224`；主强调青绿 `#5eead4`、辅靛蓝 `#818cf8`、品红 `#f472b6`、金 `#fbbf24`（仅用于 veto/警示）；玻璃面板 `rgba(15,24,44,.78)`＋1px 高光边＋背景噪点纹理。
- **字体**：标题 Sora＋思源黑体（Noto Sans SC），关键数字 Sora/Bricolage 等宽几何风；Google Fonts CDN，失败回退 PingFang/YaHei（不影响打开）。
- **版式**：每页一条核心结论作为"页眉金句"；12 列隐形网格、充足留白、统一标题区与页脚（编号/来源/密级）。
- **动效（克制）**：页面 blur/fade 入场、子元素 stagger、图表进入视口才初始化并播放动画、背景粒子常驻；切页时暂停不可见页渲染。

### 4.3 高技术力图表清单
1. **3D 立体柱状图**（echarts-gl `bar3D`）：市场规模年度增长，金属渐变柱体、地面网格投影、自动视角。
2. **3D 竞争定位沙盘**（`scatter3D`）：三轴＋气泡体量，可鼠标旋转/缩放，本项目气泡用独特描边脉冲。
3. 热力对比矩阵、六维雷达、南丁格尔玫瑰、漏斗、力导向 Agent 网络（消息沿边流动）、KPI 计数器。
4. 自研图形：三级阶梯升级图、增长飞轮、SWOT、Persona——纯 SVG/CSS，保证风格统一。

### 4.4 生成艺术（algorithmic-art 哲学：「协作星群 / Agent Constellation」）
- **哲学**：九个被赋予角色的粒子（1 协调者居中＋8 专家环绕）在多层噪声场中保持轨道；节点间按 FIPA ACL 节奏发射带寿命的光脉冲消息；冲突发生时两束脉冲相向而行、由协调者节点引出金色仲裁波。秩序从局部规则中涌现——隐喻 SSOT 与群体决策。
- 种子随机（固定 seed=20261013，可复现）、粒子数随屏幕 DPR/尺寸自适应、`requestAnimationFrame` 且切页自动降频。
- 封面与四个分隔页使用同一引擎的不同密度配置，保证全篇视觉母题统一；致谢页粒子汇聚成网络徽标。
- 不套用 algorithmic-art 技能的独立 viewer 模板（其 Anthropic 侧边栏与演示形态冲突），改为将该哲学**内嵌为本报告的活背景引擎**，这是对该技能在演示场景下的正确适配。

## 八、风险与应对
- **CDN 加载慢/失败**：多源回退＋图表降级摘要卡；脚本 `defer`、DOM 占位骨架。
- **3D 与粒子同时运行掉帧**：非激活页销毁/暂停渲染、DPR 上限 2、粒子数自适应、尊重 `prefers-reduced-motion`。
- **字体未加载闪烁**：`font-display: swap`＋完善本地回退栈。
- **数据口径争议**：统一标注"公开资料/研究测算"，措辞用"约/超"，与 SRS V4 表述不冲突。
