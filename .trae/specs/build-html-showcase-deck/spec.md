# 校园二手交易 Multi-Agent 项目演示 HTML（类 PPT） Spec

## Why
答辩与项目展示需要一个可在浏览器直接播放的「类 PPT」演示页：浅色主题、五篇章各自固定一张背景图，并把项目已有的全部成果材料——4 份 HTML 报告（竞品市场调研报告、系统流程图、项目甘特图、系统测试报告）与 9 份 Word 文档（软件需求规格说明书 V4、项目风险计划 V1、第 1/3/4/5/6/7/8 周周报）——完整内嵌；其中 Word 文档必须像 WPS 一样在仿真窗口中通过鼠标滚轮上下阅读。整体要求世界顶尖前端水准、超级精美。

## What Changes
- 新增演示目录 `ppt/校园二手交易Multi-Agent项目演示/`：
  - `校园二手交易Multi-Agent项目演示.html`：演示主入口（单文件 deck，结构/样式/脚本内联）。
  - `images/`：从项目根 `html_PPT_背景图/` 复制的 5 张背景图（教室.jpg、星空城市.jpg、琉璃金蓝海.jpg、科技办公室.jpg、科技校园.jpg）。
  - `docs/`：9 份 Word 文档用 Pandoc 预转换生成的自包含 HTML（图片 base64 内嵌），套用统一的「WPS 白纸 + A4 纸页」阅读样式。
- 演示分为 **5 个篇章**，每个篇章内所有幻灯片固定使用同一张背景图：

  | 篇章 | 背景图 | 内容 |
  |---|---|---|
  | 序篇 · 项目总览 | 星空城市.jpg | 封面（生成式艺术）、目录、项目概览（9 Agent / 技术栈 / V1–V5 迭代） |
  | 壹 · 需求与市场 | 琉璃金蓝海.jpg | 篇章分隔页、竞品市场调研报告、软件需求规格说明书 V4 |
  | 贰 · 架构与流程 | 科技校园.jpg | 篇章分隔页、交易主链路 × 冲突三级决策系统流程图 |
  | 叁 · 计划与风险 | 教室.jpg | 篇章分隔页、项目甘特图（W1–W8）、项目风险计划 V1 |
  | 肆 · 周报与质量 | 科技办公室.jpg | 篇章分隔页、7 期周报合辑、系统测试报告、总结致谢封底 |

- **HTML 报告嵌入**：每份报告以一个仿真「浏览器窗口」（标题栏 + 地址栏质感 + 内容区）承载 `<iframe>`，iframe 指向项目根对应 HTML（相对路径 `../../`），保留报告原有 ECharts/SVG 动画与截图资源；内容区可随鼠标滚轮原生滚动。
- **Word 文档 WPS 式嵌入**：每份 docx 以仿真「WPS 文字窗口」承载——顶部仿 Ribbon 工具栏（开始/插入/页面布局等视觉，只读）、下方浅灰工作台中的白色 A4 纸页、纸边投影；iframe 内为转换后的文档 HTML，**鼠标滚轮上下移动文档**；窗口底部显示文档名、页码/滚动提示。7 期周报合为一个窗口，通过顶部「第1周/第3周/…/第8周」标签切换加载。
- **类 PPT 交互**：纵向全屏 scroll-snap 翻页；右侧圆点导航（按 5 篇章分组）、顶部进度条、左下角篇章名与页码；键盘 `↓/→/Space/PageDown` 下一页、`↑/←/PageUp` 上一页、`F` 全屏、`Esc` 退出；提供悬浮前后翻页按钮。
- **浅色主题**：白色磨砂玻璃内容面板（`rgba(255,255,255,…)` + `backdrop-filter` 模糊与饱和）、深蓝灰文字、克制的单一蓝色主强调色 + 琉璃金点缀；深色「星空城市」背景叠加足够不透明度的浅色霜化渐变，保证整体仍是浅色观感且文字对比度达标。
- **生成式艺术**（algorithmic-art 技能思想）：封面与篇章分隔页运行一个轻量 p5.js（CDN）/Canvas 生成式「多智能体星链」算法——种子可复现的粒子场，节点之间按距离涌现连接，隐喻多 Agent 协作；自动适配背景明暗（封面上用青金亮色、浅色分隔页上用蓝金低透明度）；`prefers-reduced-motion` 时静帧、加载失败时不遮挡内容。
- 精致动效：入场分级淡入上浮、背景 Ken-Burns 缓慢呼吸、面板与按钮的 hover/焦点反馈；动效克制流畅（遵循 frontend-skill）。
- 响应式：以桌面 16:9 答辩投影为主（≥1280px 精修），笔记本 1366px 与 1920×1080 均可用；窄屏下窗口面板自适应缩放，不出现横向滚动条。
- **BREAKING**：无。纯新增展示资产，不修改任何业务代码与现有文档。

## Impact
- Affected specs：无（全新展示物，独立于业务系统规格）。
- Affected code/files：
  - 只读引用：项目根 4 份 HTML 报告及其资源目录 `竞品调研_assets/`、`docs/test-report-assets/`（通过相对路径 iframe 引用，不复制、不改动）。
  - 只读解析：2 份 docx + `周报/` 下 7 份 docx。
  - 只读素材：`html_PPT_背景图/` 下 5 张 jpg（复制到 deck 的 images/ 目录）。
  - 新增输出：`ppt/校园二手交易Multi-Agent项目演示/` 下主 HTML、`images/`、`docs/`。
  - 不触碰：后端、前端应用、Agent 内核、测试、现有报告。

## ADDED Requirements

### Requirement: 五篇章固定背景
系统（演示页） SHALL 恰好包含 5 个篇章，每个篇章内的每一张幻灯片都使用该篇章指定的同一张背景图全屏铺满（cover + center），5 张背景图必须全部实际使用，且每张图在任何分辨率下不变形、关键内容不被面板遮挡。

#### Scenario: 浏览全部篇章
- **WHEN** 观众从封面逐页翻到封底
- **THEN** 依次看到星空城市 → 琉璃金蓝海 → 科技校园 → 教室 → 科技办公室 5 种背景，且同一篇章内翻页背景保持不变（允许极缓慢 Ken-Burns 呼吸效果）。

#### Scenario: 直接跳转篇章
- **WHEN** 观众点击右侧圆点导航中任意篇章/页
- **THEN** 页面平滑滚动到该幻灯片，其背景与所属篇章一致。

### Requirement: 浅色高级感主题
演示页 SHALL 采用浅色主题：内容承载于高不透明白色磨砂玻璃面板之上，正文使用深蓝灰近黑文字，保证在所有 5 张背景（含偏暗的星空城市）上文字对比度 ≥ 4.5:1；全页限定两种字体、一个蓝色主强调色与一个金色点缀，整体精致克制。

#### Scenario: 深色背景上的可读性
- **WHEN** 播放到使用星空城市背景的序篇幻灯片
- **THEN** 背景上覆盖浅色霜化层，标题/正文/按钮均清晰可读，页面整体观感仍为浅色调而非深色 PPT。

### Requirement: 四份 HTML 报告完整内嵌
演示页 SHALL 内嵌竞品市场调研报告、系统流程图、项目甘特图、系统测试报告共 4 份 HTML：每份独占至少一张幻灯片，以仿真浏览器窗口包裹 iframe 指向原报告相对路径；报告内原有图表（ECharts）、SVG 动画与本地截图必须正常加载，且可在窗口内滚动查看全部内容。

#### Scenario: 窗口内阅读报告
- **WHEN** 观众在报告幻灯片上将鼠标置于窗口内容区并滚动滚轮
- **THEN** iframe 内报告上下滚动（甘特图图表、流程图动画、测试截图均可完整浏览），外层幻灯片不翻页。
- **WHEN** 鼠标移出窗口后滚动滚轮或使用键盘/导航按钮
- **THEN** 可正常切换到上/下一张幻灯片。

### Requirement: Word 文档 WPS 式滚轮阅读
演示页 SHALL 以仿真 WPS 文字窗口内嵌全部 9 份 Word 文档（需求规格 V4、风险计划 V1、7 期周报）：顶部为仿 Ribbon 工具栏视觉，内容区为浅灰工作台上的白色 A4 纸页与投影，文档经 Pandoc 预转换为自包含 HTML（图片不丢失、表格样式完整），观众通过鼠标滚轮即可像 WPS 一样上下移动文档；周报 7 期通过标签在同一窗口内切换。

#### Scenario: 阅读需求规格说明书
- **WHEN** 观众进入「软件需求规格说明书 V4」幻灯片
- **THEN** 看到 WPS 风格窗口、文档标题与 A4 白纸首页，滚轮可连续向下阅读全部章节与表格，图片正常显示。

#### Scenario: 切换周报期数
- **WHEN** 观众在周报合辑窗口点击「第3周」标签
- **THEN** 窗口内加载第 3 周周报并回到页首；7 个标签（第 1、3、4、5、6、7、8 周）全部可切换、内容各不相同。

### Requirement: 类 PPT 导航与放映
演示页 SHALL 提供全屏逐页放映体验：scroll-snap 纵向翻页、右侧分组圆点导航、顶部进度条、页码与篇章名指示、悬浮前后翻页按钮、键盘快捷键（↓/→/Space 前进、↑/← 后退、F 全屏、Esc 退出）、URL 刷新后不报错；放映时不出现浏览器横向滚动条。

#### Scenario: 键盘放映
- **WHEN** 观众按 F 进入全屏后逐次按 Space
- **THEN** 幻灯片逐张前进，圆点、进度条、页码同步更新；按 Esc 退出全屏。

### Requirement: 生成式艺术点缀
演示页 SHALL 在封面与篇章分隔页加入种子化、可复现的轻量生成式粒子艺术（多智能体星链：节点运动、近距连网、隐喻 Agent 协作），动画在普通笔记本上保持流畅（单页 CPU 占用低、离场自动暂停），在用户开启减少动态效果偏好时降级为静帧。

#### Scenario: 降级
- **WHEN** 浏览器开启 prefers-reduced-motion 或 WebGL/Canvas 不可用
- **THEN** 分隔页仍完整呈现标题与装饰，不出现空白或报错。

### Requirement: 交付物与验证
最终交付 SHALL 为 `ppt/校园二手交易Multi-Agent项目演示/校园二手交易Multi-Agent项目演示.html` 单入口，所有资源使用相对路径，断网情况下背景、9 份转换文档、4 份报告本体及其截图均可打开（仅 p5/字体/ECharts 等沿用现有报告的 CDN 依赖允许联网）；交付前运行 ppt-page 校验脚本并在浏览器中逐页实测截图核对。

#### Scenario: 离线打开
- **WHEN** 断网后直接双击主 HTML
- **THEN** 5 张背景、9 份 Word 转换页内容、4 份报告的图文（截图/SVG）正常显示；仅 CDN 字体与 ECharts 图表可能降级，页面布局不破。

## Non-Goals
- 不修改、不重构后端/前端应用、Agent 内核与任何现有报告文档。
- 不提供 Word 在线编辑能力（只读查看器）。
- 不自动导出 PPTX/PDF（如后续需要可另行处理）。
- 不为演示页额外虚构业务数据；摘要文案仅提炼自被嵌入文档的真实内容。
