ACL 消息流 · 动态推演
三级处理阶梯冲突一旦检出，按级别自动升级；安全类判定拥有最高优先级
LEVEL 1

对等协商

冲突初发且当事 Agent 可直接谈判：限时 ≤3 轮自动让步、给出纳什参考价、解释规则并允许补充材料。覆盖 C1 议价僵持、C3 审核申诉初审。

成功 → 留痕并恢复主流程；失败 → 升级二级
LEVEL 2

协调仲裁

协调者主持：按全局效用函数 U＝0.25 满意度＋0.20 成功率＋0.30 安全性＋0.15 公平性−0.10 处理成本评分，相关 Agent 以“票权×置信度”加权投票，出具含依据裁决书。覆盖 C4/C5/C6。

被拒或分歧过大 → 暂缓操作并升级三级
LEVEL 3

人工兜底

涉资金 / 违禁 / 校园安全或超金额阈值：interrupt 立即挂起并冻结相关操作，仲裁 Agent 汇总全链路证据包提交管理员终裁，裁决写回黑板并联动信用处罚。

人工裁决 → 恢复或终止流程；动作强制留痕
议价：买价不降、卖价不升，违例拒收 时限：默认 5 轮 / 120 秒，超时破裂并推荐同类商品 抢单：下单时间 → 信用分 → 支付完成 三优先裁决 锁：锁令牌 + 乐观版本号 + 超时点，失败必释放 veto：违禁 / 欺诈冻结，任何裁决不可覆盖 SSOT：信息冲突以黑板为准自动纠正并记录来源 降级：结构化输出 → 校验 → 重试 3 次 → RuleLLM / 转人工 覆盖：C1–C8 八类场景，≥10 个剧本一键回放对照
