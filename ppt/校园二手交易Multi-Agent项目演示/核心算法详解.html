算法 02 · NEGOTIATIONNash bargaining solution
02纳什议价参考价 + 50% 梯度让步

让买卖双方朝同一个均衡点收敛，而不是乱砍价

参考价与让步规则

对称纳什议价解（议价能力 1 : 1）
P*nash = ( Pbuyer + Pseller ) / 2
P_seller = 挂牌价 × 0.85 （卖家保留价）
①
梯度让步 50%

买家：target = last + (min(卖家要价) − last) × 0.5
卖家：target = start − (start − 保留价) × 0.5，且不低于保留价。

②
成交判定

本轮目标价 ≥ 对方最优出价 → would_deal = true，按对方价格成交并建单预占锁。

③
僵持破裂（C1）

连续 5 轮出价区间无交集 → 会话 terminated，纳什价留痕，并向买家推送同类商品推荐。

04三方加权投票 · ±0.5 双阈值裁决

风险意见打架时，让「票权 × 置信度」而不是嗓门决定

计票公式

信用 / 审核 / 协调者 三方求和
S = Σ wi · ci · vi
vᵢ ∈ {−1 反对, 0 弃权, +1 赞成}　cᵢ ∈ [0,1] 置信度
投票方票权 w票值规则
信用评价 Agent0.50风险 high/med/low → −1/0/+1
内容审核 Agent0.20订单维度风险投票；不可用则弃权 (0, 0.5)
协调管理 Agent0.30买家信用 <70 / <80 / 否则 → −1/0/+1
≥
S ≥ +0.50　放行

进入等待支付人工门，沙箱支付后订单完成。

≤
S ≤ −0.50　拦截

取消订单并释放预占锁，冲突事件转人工备案。

≈
−0.50 < S < +0.50　灰区

证据不足以下定论，升级三级人工终裁，避免机器误杀 / 误放。
