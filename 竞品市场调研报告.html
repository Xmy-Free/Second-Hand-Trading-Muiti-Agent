协调仲裁
二级 · 全局效用评分 + 加权投票
票权 × 置信度加权；协调者出具含依据裁决书，覆盖 C1–C7 议价、抢单、推荐偏差、信用分歧等场景
L3
人工兜底
三级 · interrupt 冻结 → 证据包 → 终裁写回黑板
涉资金/违禁/校园安全即升级管理员，全程留痕、联动信用处罚，决策轨迹可回放
VETO
安全一票否决不可覆盖：内容审核 Agent 对违禁品/欺诈交易拥有最高优先级否决，任何投票与效用得分均不得推翻；确定性规则优先于模型输出，无 API Key 时 RuleLLM 全量兜底。
